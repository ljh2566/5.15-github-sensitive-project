# 메인 화면 구조

## Header
- 서비스 로고
- 간단한 설명 문구

## Main Section
- 텍스트 입력 영역
- 분석 버튼
- 결과 카드

## Footer
- 제작 정보
- GitHub 링크

## 버튼
- border-radius: 999px
- hover 애니메이션 적용
- 검정 테두리 사용

- 흰색 배경
- 연한 회색 테두리
- 충분한 padding

- Pretendard
