# PRD.md

# 감성 분석 서비스 제품 요구사항 문서

## 프로젝트 목표

사용자가 입력한 텍스트의 감정을 분석하여
긍정 / 부정 / 중립 결과를 제공하는 웹 서비스를 제작한다.

비전공자도 쉽게 사용할 수 있는 직관적인 UI를 목표로 한다.

---

# 핵심 사용자

## 주요 사용자
- 학생
- 취업 준비생
- SNS 사용자
- 감정 분석을 체험하려는 일반 사용자

---

# 핵심 기능

## 1. 텍스트 입력
사용자가 문장을 입력할 수 있어야 한다.

### 완료 조건
- 최소 1글자 이상 입력 가능
- 최대 1000자 제한

---

## 2. 감성 분석
OpenAI API를 사용하여 감정을 분석한다.

### 출력 항목
- 긍정 / 부정 / 중립
- 신뢰도(%)
- 분석 이유

### 완료 조건
- 결과가 3초 이내 표시
- JSON 형식 유지

---

## 3. 결과 저장
분석 결과를 Supabase에 저장한다.

### 저장 항목
- 입력 텍스트
- 감정 결과
- 신뢰도
- 생성 시간

---

## 4. 오류 처리
오류 발생 시 사용자에게 안내 메시지를 표시한다.

### 예시
- 입력값 없음
- API 실패
- 서버 오류

---

# 비기능 요구사항

## 성능
- 첫 화면 로딩 3초 이하
- API 응답 5초 이하

## 보안
- API Key 노출 금지
- 환경 변수 사용

## 접근성
- 버튼 클릭 영역 확보
- 모바일 대응

---

# 성공 기준

## 사용자 기준
- 결과를 쉽게 이해 가능
- UI가 복잡하지 않음

## 기술 기준
- Vercel 정상 배포
- Supabase 저장 성공
- API 오류 처리 성공
